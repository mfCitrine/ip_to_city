# 融合算法设计

ipgeo 的核心是把多个"各自不完美"的 IP 库融合成一个"更准"的库。
本文档说明融合规则、国家仲裁与置信度逻辑。

## 一、整体流程（Phase 2）

```
多源原始数据
    │
    ▼
归一化（统一字段、CIDR、语言）
    │
    ▼
分层融合：
  · 中国区 → 纯真（省市区最精细）
  · 非中国区 → DB-IP（全球城市级）
    │
    ▼
国家归属仲裁（iptoasn origin AS）
    │
    ▼
人工订正（corrections.csv，最高优先级）
    │
    ▼
输出 mmdb + CSV
```

## 二、分层融合策略

| 区域 | 主数据源 | 说明 |
|---|---|---|
| 中国区 | 纯真 IP 库 | 省市区精细到区县，纠正 DB-IP 的国内城市错误 |
| 非中国区 | DB-IP | 全球城市级，CC BY 4.0 可再分发 |

## 三、国家归属仲裁（关键）

纯真与 DB-IP 对国家归属可能冲突（典型如 `101.47.x`：纯真判中国、
DB-IP 判新加坡）。仲裁规则：

1. **两者一致时不仲裁**（避免 anycast IP 的 origin AS 误导——
   如 `114.114.114.114` 是南京电信 anycast DNS，其 origin AS 却是美国节点）。
2. **两者冲突时用 iptoasn 的 origin AS 国家仲裁**：
   - iptoasn 判中国 → 纯真对，保留中国区。
   - iptoasn 判国外 → 纯真错（该段已转让境外），剔除中国区，交 DB-IP 覆盖。

实例：`101.47.16.0/20` 的 origin AS 是 `AS150436 Byteplus Pte. Ltd.`（字节跳动
新加坡子公司），iptoasn 判 SG，故判为新加坡——纯真的"杭州"是历史遗留错误。

## 四、人工订正优先级

`corrections.csv` 中的订正**最高优先级**，覆盖一切自动结果（含仲裁结果）。
合并时人工订正排在最后写入，利用 mmdb 后写覆盖特性生效。

## 五、置信度打分（confidence 0~100）

| 情形 | 置信度 |
|---|---|
| 人工订正 | 100 |
| 纯真中国区（经仲裁保留） | 80 |
| DB-IP 非中国区 | 60 |
