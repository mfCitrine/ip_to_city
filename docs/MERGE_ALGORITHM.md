# 融合算法设计

ipgeo 的核心是把多个"各自不完美"的 IP 库融合成一个"更准"的库。本文档说明融合规则与置信度打分逻辑。

## 一、整体流程

```
多源原始数据
    │
    ▼
归一化（统一字段、CIDR、语言）
    │
    ▼
前缀合并（相同归属的相邻网段合并）
    │
    ▼
多源投票融合（每个网段，各源投票）
    │
    ▼
置信度打分 + 类型标注
    │
    ▼
输出 mmdb + CSV
```

## 二、多源投票规则

对每个 IP 前缀，收集各数据源的判定，按**层级**独立投票：

1. **国家层**：RIR 数据为权威，其它源一致则高置信；冲突时以 RIR 为准。
2. **省/州层**：GeoLite2、DB-IP、纯真各自给出结果，取多数一致。
3. **城市层**：同上，但要求至少 2 个来源一致才算"高置信"。

## 三、置信度打分（confidence 0~100）

| 情形 | 置信度 |
|---|---|
| 国家层：RIR + ≥2 源一致 | 99 |
| 国家层：仅 RIR | 95 |
| 省市层：≥3 源一致 | 90 |
| 省市层：2 源一致 | 80 |
| 省市层：仅 1 源 | 60 |
| 各源冲突 | 40（取可信度最高源） |
| 无数据 | 0 |

## 四、类型标注（IP 类型）

基于 ASN 与数据源特征标注网络类型：

| 类型 | 判定依据 | 精度承诺 |
|---|---|---|
| `isp` | 家宽/企业出口 | 城市级 |
| `mobile` | 移动运营商（CGNAT） | 省级 |
| `idc` | 云/IDC/托管 ASN | 机房归属 |
| `vpn` | 代理/VPN ASN | 机房归属 |

## 五、人工订正优先级

`data/corrections.csv` 中的订正**最高优先级**，覆盖一切自动结果。合并时人工订正排在最后执行。

## 六、参考论文

- PASSPORT (arXiv:1905.04651)：多个不准确来源通过 ML 融合可逼近高精度。
- GraphGeo (KDD'22)：图神经网络街道级 IP 定位。
- Octant / CBG / TBG：延迟测量定位经典方法。
